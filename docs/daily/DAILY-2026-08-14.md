## 二、今天做了什么

### 1. 方案 1 — Lazy 历史维护（`ActionSequenceTracker`）

- **无进框帧**：只更新窗口内 **warm track**（曾进框且仍在 30 帧窗口内的人）
- **有进框帧**：本帧 `feature_rows` **全量写入**（与改前进框帧口径一致，避免进框前无历史导致告警漂移）
- 离线 `collect_sequences` 不受影响（`track_ids=None` 仍更新全部）

### 2. 方案 2 — 历史裁剪

- 每帧删除 `frame_idx < t - window - step` 的旧序列点
- 超过 `window + 15` 帧无更新的 track 从 `_hist` 移除，防止长跑 dict 膨胀

### 3. 方案 6 — 延后 GBDT（`pipeline/runner.py`）

- 先完成配对 Logistic 打分 + EMA
- 仅当 `smooth_v >= pair_threshold` 时才调用 `features()` + `action_gate.allow()`
- 低分 hit 不再白跑 GBDT

### 4. 单测

- 新增 `tests/test_action_temporal.py`（lazy / warm / 裁剪 / 全量兼容）
- 全仓 **23** 个 pytest 通过
