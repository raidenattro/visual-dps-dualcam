# 工作日报（2026-08-26）

> 分支 **`exp/rzy`**。主题：**对向双路同一货架，三角化抬 3D**，验证单路射线欠定能否被第二路解开。

---

## 一、背景

单路 LEAP：每个 2D 点只钉一条射线，「手在筐里」和「停在框前」投影可以几乎一样。  
现场给了 1-3 组两端对打拼接片（2560×720、25fps、约 17:03，已对齐），用来看双路有没有提高 3D 精度的可能。不是立刻改线上推理。

---

## 二、今天做了什么

### 1. 双路标注 + 对向反解

- 标注页：墙1 = 人伸手那面（两路标同一面），点序相对**本机** ①顶远 ②顶近 ③底近 ④底远
- 两路各自 `solve()`，再按对向角序 `[1,0,3,2]` 用 Umeyama 把 B 对到 A
- 原片 moov 在尾、`display:none` 的 video 无法 `drawImage`：已 copy+faststart，改成两路可见 `<video>` + `object-position` 裁左右半幅

### 2. 两路 RTMPose → 三角化

- 解释器：`visual-dps` conda（rtmlib + GPU ORT），须带上 `nvidia/*/lib` 的 `LD_LIBRARY_PATH`
- 模型只读：`visual-dps-0817-deploy/weights/rtmpose_onnx/`
- stride=10（约 2.5fps）跑完全片；腕到墙1 巷道内侧为正，`d≤0` = 伸进货架

### 3. 网页同步回放

- `/` 标注，`/play` 左右实拍 + 中间 3D 骨架
- 左右按 16:9 居中，避免格子把半幅拉高裁切
