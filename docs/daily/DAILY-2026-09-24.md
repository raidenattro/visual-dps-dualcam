## 一、背景：为什么 3D 抬升在同侧机位下不够用

### 1. 之前的原理（三角化 + 贴墙判定）

```
左路 2D 关键点 ──┐
                 ├─→ 各自反解为世界系射线 → 两条射线最近点 = 3D 关节 (xyz)
右路 2D 关键点 ──┘
                                    ↓
              腕点 xyz 到墙平面的有向距离 dL/dR ≤ contact_m 且 (Y,Z) 落在某格 → 报警
```

依赖链：**每路 4 个墙角 → `solve_scene` 解出焦距 f、相机位置 C、朝向** → 像素射线 → 三角化。
17 点全部抬 3D，再算腕到墙的距离。回放画整具骨架。

### 2. 同侧机位下它坏在哪

今天已把机位调成同侧（144/24 都在巷道同一端），量出来的问题：

| 问题 | 数值 | 后果 |
|------|------|------|
| 两路视线交会角小 | test2 ≈ 11°，144-24 基线仅 ~0.2 m | 沿视线方向误差 ≈ R²·σpx/(f·B⊥) ≈ **1.3 cm / 像素**，1 像素抖动 → 腕点前后飘几厘米到十几厘米 |
| 误差方向 | 85% 落在 Y/Z，15% 落在 X（朝墙） | 恰好「离墙多远」这个量最不稳 |
| 单面墙标定的 f–距离歧义 | R 路 f 600→800 时 C 距离 1.84→2.55 m，残差只从 8.0 变到 8.4 px | 相机位置 ±30 cm 不可辨，骨架整体浮高 ~20 cm、拉长 ~20% |
| 广角桶形畸变未建模 | 85° hFOV，四角处 5–12 px 残差 | 墙面本身就漂 |

结论：**同侧双机的三角化根本给不出可靠深度**，而「碰没碰墙」恰恰是个深度问题。
前面试过的骨长约束、物理量定住等都在修补三角化结果，治标不治本，已全部回滚。

## 二、现在的方法：墙面单应（homography）

### 1. 核心观察

我们不需要 17 点 3D，只需要回答两个问题：**腕点在墙面哪个位置**、**腕点是否真的在墙面上**。
而**墙是平面**。对一个平面，像素坐标 ↔ 平面坐标是一个 3×3 单应矩阵 H，
**4 个墙角刚好把 H 定死**，不需要焦距、相机位置、朝向中的任何一个。

```
uv  ──H_L──→  (z, y)_L     墙面坐标：z 沿墙 0..2.2，y 离地 0..2.0
uv' ──H_R──→  (z, y)_R
```

- 腕点**真的贴在墙面上**：两路视线都穿过墙上同一个物理点，H_L、H_R 给出的落点**重合**。
- 腕点**悬在巷道里**：两条视线各自延长到墙面，落在墙上**两个不同的点**，分开距离随离墙距离单调增。

所以「碰没碰」= 两路落点重合距离 `dist ≤ τ`；「进哪个格」= 两落点中点落在哪个 `slot_mesh` 格内。
这是把一个不可靠的三维深度问题，换成了一个只依赖 4 个角点、纯二维的一致性检验。

### 2. 为什么它不怕同侧机位

| | 三角化 | 单应 |
|---|---|---|
| 需要什么 | f、C、朝向（解出来的，有歧义） | 4 个角点像素（标出来的，无歧义） |
| 误差敏感度 | 沿视线 1.3 cm/px，交会角越小越差 | 墙面内 ≈ 像素比例，与交会角无关 |
| 深度判定 | 直接量 X，最差的那一维 | 不量深度，量两路是否一致 |
| 畸变影响 | 进入 f/C 求解，被放大 | 只影响墙面坐标本身，几厘米级 |

代价：**两路必须看到同一面墙**（要各自有 H）。同侧机位天然满足；对侧 A/B 各看一面则不行。

### 3. test2 验证数字（重出 dump 后）

以三角化的 dL/dR 分组（<10 cm 记「贴墙」，>40 cm 记「巷道」），看单应重合距离分布：

| 组 | n | p10 | p50 | p90 | ≤τ=0.15 |
|---|---|---|---|---|---|
| 贴墙 | 787 | 0.025 | **0.079** | 0.219 | 79.5% |
| 巷道 | 2260 | **0.884** | 3.27 | 11.6 | **0.1%** |

贴墙组中位 8 cm，巷道组 p10 就已 88 cm，中间隔了一个量级；噪声底 ≈ 3.4 cm 远小于格子 0.55×0.45 m。
回放看下来，红点起落基本与真实伸手一致，**效果比预期好**。

144-24 数据：贴墙 p50 5.4 cm，但巷道组 ≤τ 有 6.3%（p10 = 0.346）。
原因是该机位基线只 0.2 m，重合距离对深度不够敏感；后续在播放器里把 τ 收到 0.08–0.10 对比即可，不必重 dump。

## 三、今天做了什么

### 1. `scripts/plane_contact.py`（新）

- `homography_to_wall(quad, W, H, base)`：像素四角（①顶远 ②顶近 ③底近 ④底远）→ 墙面 (z, y)。
- `PlaneContact.from_calib(calib)`：自动收两路都标齐四角的墙（test2 只有 81；144-24 有 81/82）；
  `wall_x`/`z_near` 沿用 `solved.walls`，只为回 3D 画图和复用现有 `slot_meshes` 格子。
- `wrist(uvL, sL, uvR, sR)` → `{dist, zy, zyL, zyR, sgn, in, cell, contact}`。
  `sgn` 是有向分离：>0 悬在巷道，<0 伸进货架（用「墙心往巷道推 0.5 m 后的分离方向」当参考）。
  多面墙取重合最小且落点在墙面范围内的那面。
- 只依赖 numpy / cv2，`person()` 只需两路腕点 2D，可以直接接实时链路。

### 2. `scripts/dump_skel3d.py`

- 每人加 `pc` 字段 `{"9": {...}, "10": {...}}`，用平滑后 2D（`Lsm/Rsm`）算，held 帧不算。
- payload 加 `plane_contact`（墙位置 / τ / 上表那份分布统计），新参数 `--tau`（默认 0.15）。
- 三角化、平滑、落地锚定等旧输出全部不变。

### 3. `scripts/dualcam_player.html` 腕点模式

- 底栏加「腕点模式」复选框，**默认勾选**：隐藏骨架，3D 里画每腕墙面落点球 + L/R 落点连线（线长即重合距离），
  红 = `dist ≤ τ` 且在格内，灰 = 悬空；货格高亮走原 `slotObjs`。
- 左右实拍只画两个腕点，旁标 `墙1 r3c3 · 0.13m`。阈值输入框此时是 τ；取消勾选恢复原三角化逻辑与原阈值。
- `serve_dualcam.py`、标注页零改动（标注页只提交了之前遗留的 UI 修复）。

### 4. `tests/test_plane_contact.py`

合成同侧双机投影墙角 → H 复原墙面坐标 < 1 mm；面上点重合、离面 0.1/0.3/0.6 m 分离单调增；
伸进货架 `sgn < 0`；低分腕点跳过。3 个用例通过。
