## 一、背景

8.26 双路三角化已能把「伸进墙」和「停在通道」在深度上分开。今天要把墙切成货位，看腕点碰到哪一格。  
拣货定义不变：**接触拣货墙 = 一次拣货**；格子只用来区分取的是哪一格，不描筐口、不引入筐深。

此前试过对向 2D 映射、分路标近处列、橙点配对、开口内缩，两路格子都对不齐。已回滚到墙角+反解，再改成「墙上只有一份 3D 网格」。

---

## 二、今天做了什么

### 1. 墙面 3D 货格（参考分区）

- 绿点墙角 + 反解照旧。货格在 **solved 墙矩形** 上均匀切 rows×cols，顶点钉在墙面上。
- 两路画面都是同一套 3D 点的投影；在看得清的那路拖格点，改的是墙上分区。
- 一路两面墙都能标：墙1 绿、墙2 紫；点表格或点画面切换。可「生成本墙」或「两墙都生成」。
- 存 `output/calib/dual_1-3.json` 的 `slot_meshes`。

### 2. `/play` 贴墙变红

- 腕点到该墙有向距离 ≤ 10 cm，且 (Y,Z) 落在某一格内 → 该货位 3D / 左右实拍变红，HUD 写 `墙1 r1c2`。
- 未保存货格时按墙面均匀 4×4 兜底。

### 3. 几何结论（为何复原不准）

| 原因 | 含义 |
|------|------|
| 均匀切开 ≠ 现场隔板 | 墙四角矩形按行×列等分，真实货位宽高往往不均 |
| `align_rms=0` 不保证同一物理角 | 只说明两路墙矩形尺寸一致；远角仍可能点偏 |
| 反投影残差 5–12 px | 墙平面本身有误差，格线会跟着漂 |
| 两路看起来不贴筐 | 正常：格子在墙上，筐口在墙前；不要拿筐口验收对齐 |

因此：**标注复原只作参考可视化**，货位 ID 不能当精确 GT，也不能据此改线上配对。

否掉：2D 互相反投、橙点立体、开口内缩——都在解「套筐口」，和「接触墙面分区」不是同一问题。
