## 一、背景

0727 离线包部署后，同帧 infer / worker 的 `[PIPELINE] time=` 相差约 8 小时（infer 为 UTC、worker 为 CST）。根因：推理 slim 镜像常无 **tzdata**，`datetime.now()` 忽略 `TZ=Asia/Shanghai`；worker/UI 挂载 `/etc/localtime` 则正常。

现场样例（camera=93 frame=78）：infer 三阶段 → worker received/done → PREFILTER PASS → COLLISION HIT/ALARM → event_published → callback ACK 200，**run_id 对齐**。

## 二、代码变更

### 1. `services/wall_clock.py`

- 从 **`TZ` 环境变量**（默认 `Asia/Shanghai`）解析 `ZoneInfo`
- 无 tzdata 时对国内时区名 **回退 UTC+8**，避免 infer 落到 UTC
- 新增 `wall_datetime()`、`log_timezone_name()`

- `callback_reporter._now_iso()` 改用 `wall_datetime()`
- infer 容器 bind mount **`services/wall_clock.py`** + **`/etc/localtime:ro`**
- `scripts/deploy-only/infer-bind-mounts.sh` 校验列表补 `wall_clock.py`
- `tests/test_wall_clock.py`：格式与无 tzdata 回退

## 四、现场生效

```bash
# UI / event-worker
docker cp app/services/wall_clock.py visual-dps-ui:/app/services/wall_clock.py
docker cp app/services/wall_clock.py visual-dps-event-worker:/app/services/wall_clock.py
docker cp app/services/callback_reporter.py visual-dps-event-worker:/app/services/callback_reporter.py
docker restart visual-dps-event-worker

# 各路 infer（或 UI 停启智能检测以挂载新 bind）
docker cp app/services/wall_clock.py visual-dps-infer-<id>:/app/services/wall_clock.py
docker restart visual-dps-infer-<id>
```

验证：infer 与 worker 的 `wall_time_str()` 输出应在同一小时（如均为 `14:xx:xx`）。
