- 镜像 tag：`20260813-feature-eventworker2-5e4f4fe`

### worker-2 多路表现

| 路数 | lag | 前端 overlay |
|------|-----|--------------|
| 较少路数 | ≈0 | 不闪烁 |
| **8 路** cam1～cam8 | **0～57 波动**（avg≈10） | **闪烁**（与 lag 同步） |
| worker-1（对照经验） | 5 路 lag=0；12 路 lag≈2000 | 见 06-28 压测 |

**结论**：worker-2 与 worker-1 **共用** `pose:stream` 单 consumer、`XREADGROUP count=1`；pick_state v5_gated 每帧 CPU 更重（worker-2 CPU **223%～355%**），8 路处于临界过载；infer GPU 仍有 headroom（~7GB / ~45% util）。

详细采样：`docs/test/LOAD-TEST-8CAM-WORKER2-2026-08-13.md`（本地，gitignore）。

## 四、Redis lag 指标说明（本日联调共识）

- **`lag`**（`XINFO GROUPS pose:stream`）：消费组 `event-workers` 中 **尚未投递给 consumer 的 pose 条数**。
- **lag≈0**：event 与 infer 同步；**lag 波动**：event 滞后于 live pose → `live_bus` 合并后碰撞框闪烁。
- 与 **pending**（已读未 ACK）、**XLEN**（stream 长度，常顶 `MAXLEN=2000`）区分使用。
