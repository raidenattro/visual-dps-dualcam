## 五、断触恢复要点

| 现象 | 处理 |
|------|------|
| 仅有 `<none>:<none>` 无 tag | 确认 `.env` 中 `VISUAL_DPS_IMAGE_TAG`，重跑对应 `build-*.sh`（Docker 复用 layer） |
| 部分镜像已有目标 tag | 只重跑缺失的脚本，勿裸跑 `docker compose build`（可能生成新时间戳 tag） |
| gpu-onnx 基于错误 lite-gpu | 构建 lite-gpu 时设 `DOCKER_TAG_ALSO_LATEST=1` 或手动 `docker tag ... :latest` |
| `.env` tag 与本地镜像不一致 | 以 `VISUAL_DPS_IMAGE_TAG` 为准重新构建，或 `docker tag` 对齐 |
