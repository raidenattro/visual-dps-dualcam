## 二、现场问题（同侧）

1019 包上线后，同侧（`layout=same_side`）和对侧（`opposite`）不一致。人已经离开取货区、身体没贴任何货架、手腕也没伸进货格，仍会报拣货，命中落在**货架边缘**那一格。

两类误触叠在一起：

| 现象 | 现场看到的 | 代码上在做什么 |
|------|------------|----------------|
| **贴近误触** | 人在通道里、手腕没进货架，仍算贴墙 | 墙在 Y/Z 上是无限平面，只比 X 向有向距离 `d`。`contact_m` 默认 0，`d < 0` 即贴墙。短基线把腕点甩过这张平面就报 |
| **边缘误触** | 人在取货区外，却记到货架端头 / 边格 | Y/Z 落不进任何货格多边形时，`contact_slots` 用最近货格兜底（`_nearest_cell_yz`），记到端头那一列或顶/底边格。日志 `contact_probe` 的 `reason=nearest_cell`，`d` 为很小的负数 |

碰撞只看左右腕（关节 9、10）。躯干、肩、肘不参与，所以「身体没碰货架」挡不住这次报警。

---

## 三、根因

### 1. 同侧配对盒被写死，现场改界面不生效

对侧配对用配置盒，躯干三角化中心出界就丢掉，不再做立体抬升（`pick_pairs` → `in_aisle`）：

- X `-1.35 ~ 1.35`
- Y `0.50 ~ 1.65`
- Z `-0.12 ~ 2.50`

同侧在 `DualcamProcessor.__init__` 里把巷道 JSON 和 `runtime_config.json` 的 `aabb` **整段换掉**：

```python
# services/event_engine/dualcam_processor.py
self.aabb = aabb_from_section(self.section, aisle)
if aisle_layout(aisle) == "same_side":
    self.aabb = AISLE_AABB_SAME_SIDE
```

常量在 `dualcam/lift.py`：

```python
AISLE_AABB_SAME_SIDE = {"x": (-1.45, 1.45), "y": (-0.15, 3.55), "z": (-2.5, 4.5)}
```

这只盒是为短基线 Y 误差放宽的，避免 `paired=0`。Z 也被放到 `-2.5 ~ 4.5`。人沿巷道走出货架（例如 Z=3 m）仍在盒内，会继续三角化。标注页「AABB X / Y / Z」和设置页「巷道 AABB」对同侧**都不生效**。

### 2. 出区腕点被记到边缘货格

`dualcam/geom.py` · `contact_slots`：`d < contact_m` 之后，Y/Z 不在格内就选最近货格，**没有距离上限**。`tests/test_dualcam_contact.py` 的 `test_contact_slots_nearest_cell_when_yz_miss` 把 Y 偏出 999 m 也仍算命中。

对侧多数时候人已在配对阶段被丢掉，走不到这里。同侧人还在正式立体路径上，区域外碰撞会一直算。

`pick_pairs` 返回空时会走 `_lift_follow`，这条路径**不查** `in_aisle`，预览帧仍会抬腕并调用 `contact_slots`。

## 四、拟提供的同侧配对盒修改（未落地）

同侧配对盒改为与对侧同一组，让出区躯干不再立体抬升：

| 轴 | 同侧现在 | 改为（与对侧一致） |
|----|----------|-------------------|
| X | -1.45 ~ 1.45 | **-1.35 ~ 1.35** |
| Y | -0.15 ~ 3.55 | **0.50 ~ 1.65** |
| Z | -2.5 ~ 4.5 | **-0.12 ~ 2.50** |

落点：`dualcam/lift.py` 的 `AISLE_AABB_SAME_SIDE`。`services/event_engine/dualcam_processor.py` 对 `same_side` 的覆盖可以保留，但覆盖值必须是上面这组，不能再放宽 Z。

改完后可观察的行为：人沿巷道走出货架（Z 超出 `2.50`）或髋高掉出 `0.50 ~ 1.65`，这一帧不再进立体配对，不再用这块抬出来的腕去算区域外碰撞。

部署：只改标注页或 `runtime_config.json` 不够。须把 `dualcam/lift.py` 更新进 `visual-dps-event-worker` 并重启。`tests/test_lift_point.py` 的 `test_same_side_aabb_keeps_points_outside_opposite_box` 锁的是「同侧盒比对侧宽」，改常量后该测试要一起改。

已知残留：`_lift_follow` / hold 续帧仍不查配对盒，出区后可能再跟一小段并算贴墙。配对盒收紧解决的是「一直停在立体路径上」；跟帧路径要另看。

## 五、后续：考虑不再使用最近货格

配对盒对齐对侧之后，边缘误触的另一半还在：腕点 Y/Z 在货格多边形外时，`contact_slots` 仍用最近货格兜底。

后续可取消 `_nearest_cell_yz`，只保留「Y/Z 落在货格多边形内且 `d < contact_m`」才报。这样人在取货区外、手腕没进货格时，不会再被记到端头那一格。

取舍：格缝上差几厘米、点刚好落在两格之间的真贴墙，会不再被兜到邻格。取消前用现场 `reason=nearest_cell` 的日志看这类点有多少、偏出多边形多远，再决定是直接去掉，还是只允许偏出几厘米。
