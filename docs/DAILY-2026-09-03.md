## 三、推理分辨率错位（commit `6316a80`）

### 现象

- cam 11–20（153 推流）Redis 报 **infer 1280×720**，关键点按 360p 坐标写 → overlay 全挤左上角。
- 根因：推理启动时 `CAP_PROP` / ffprobe 记下 720p，中途推流改 360p **未重启 infer**，且 ffmpeg rawvideo 管道按旧宽高读字节 → 帧内容错位。

### 改动

| 文件 | 说明 |
|------|------|
| `services/inference_service.py` | `_sync_infer_size_from_frame`：以 `frame.shape` 为准重算 infer 尺寸 |
| `services/rtsp_capture.py` | `vf_with_fixed_scale`：探测分辨率变化时 scale 到固定 WxH |
| `tests/test_infer_resolution.py` | 360p 帧 + 720p 探测、ffmpeg vf 单测 |

部署：重启对应 `visual-dps-infer-*`；改分辨率后仍建议重启 infer 容器。
