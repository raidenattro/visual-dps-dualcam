## 四、复跑冒烟

```bash
cd /home/hqit/workspace/visual-dps-xugang-dev/app
# 构建
docker compose --profile worker-2 build visual-dps-event-worker-2
# 起 worker（挂现网 visual-dps-internal，独立流）
docker run -d --name visual-dps-event-worker-2 --network visual-dps-internal \
  -e REDIS_URL=redis://:visual-dps-local@redis:6379/0 \
  -e POSE_STREAM_KEY=pose:stream:ew2-smoke \
  -e POSE_STREAM_GROUP=event-workers-ew2-smoke \
  -e PICK_STATE_CONFIG=pick_state/configs/pipeline.v5_smoke.json \
  -e EVENT_WORKER_ENABLE_CALLBACKS=0 -e JSON_DIR=/app/localdata/json \
  -v "$PWD/localdata:/app/localdata" -v "$PWD/app_config.json:/app/app_config.json:ro" \
  visual-dps-event-worker-2:${VISUAL_DPS_IMAGE_TAG:-latest}
# 灌消息
docker run --rm --network visual-dps-internal \
  -e REDIS_URL=redis://:visual-dps-local@redis:6379/0 \
  -e POSE_STREAM_KEY=pose:stream:ew2-smoke \
  -v "$PWD:/app" -w /app visual-dps-event-worker-2:${VISUAL_DPS_IMAGE_TAG:-latest} \
  python scripts/smoke_event_worker_2_redis.py
```

生产对照切换（同现网流时）：

```bash
docker compose stop visual-dps-event-worker
docker compose --profile worker-2 up -d visual-dps-event-worker-2
```
